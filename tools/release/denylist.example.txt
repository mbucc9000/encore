# Encore release scan: denylist format (example only; every value below is a placeholder).
#
# Copy this file to tools/release/denylist.local.txt and fill in YOUR real values: your name, your server's name,
# your home/VPN/build-machine addresses, your domain, your key file names, your user-profile paths, your Spotify
# username and real playlist names. The .local file is never exported (the export and the scanner both refuse it),
# and scan.py never prints its values: a finding shows only the denylist line number and the [label].
#
# One entry per line. Blank lines and lines starting with '#' are ignored.
#   [label] value              case-insensitive literal, found anywhere (also inside longer words)
#   [label] word:value         case-insensitive literal that must stand alone (not inside a longer word)
#   [label] case:value         case-sensitive literal
#   [label] re:regex           Python regular expression (start it with (?i) for case-insensitive)
#   allow <path-glob> <regex>  a denylist hit is ignored when a match of <regex> on the same line covers it and the
#                              file path matches <path-glob> ('**' = anything, '*' = inside one folder name)
# The [label] is optional; it only names the kind of value in reports. Typographic apostrophes match plain ones.

[owner-name] Example Owner
