      Engine & stream

      Updates

      checking...

      Encore Bridge asks GitHub for the newest version at most once a day. It sends nothing about you or this bridge except its version number; GitHub sees this network's public IP address, as with any download. To turn the daily check off, set UPDATE_CHECK=0 in settings.env (Windows: Troubleshooting → Edit settings… in the tray) or in .env (Docker).

      Jam

      Jams need a one-time check. Start a Jam in the Spotify app on another phone or computer, pick Encore as its speaker, then press Check Jam access. Until then Start and Join stay grey in the app. The check sends a single request to Spotify.

      Advanced (developer)

      Fake Jams never reach Spotify; they end by themselves after 30 min (handy for demos). Flags live in memory until a restart ("Jam edits" off hides Up Next editing during Jams only). The trace holds no ids, tokens or names.

      Catalog

      Song lists, albums, search and covers are cached here; a flush only costs a refetch. Nothing in this card talks to Spotify.
