# The only files bundle.sh copies from the exported tree into the Windows bundle. There is no app package in it:
# phones install Encore from the Encore repo in Cydia (the setup guide's step 6), so nothing of a gateway/repo/ folder
# and no .deb is ever shipped (bundle.sh checks the payload for both).
#
#   <path in the exported tree>   [<path in the bundle, under "Encore Bridge\">]   (one column: the same path)
#   !<path in the exported tree>  explicitly not shipped
#
# Every file in gateway/src must be listed or excluded: a new gateway file stops the bundle until someone decides,
# so nothing ships (or goes missing) by accident. The third-party programs (node.exe, ffmpeg.exe), the engine exe
# and the launcher exe don't come from the tree: see pins.conf and bundle.sh's --engine / --launcher.
